# mp3-tag-fixer

解决：音乐文件导入苹果音乐后，歌手和曲名乱码的问题

批量修复 MP3 中文歌名、歌手乱码的小工具。打开网页就能用，不用安装。

很多旧 MP3 的标签是用 GBK 编码写的（常见于旧版 Windows），导入 Apple Music 等软件后，歌名和歌手会显示成 `¸èÊÖ` 这样的乱码。这个工具会找出正确的信息，重新写成 UTF-8 标签。

## 使用方法

1. 下载 `index.html`，用浏览器（Chrome、Safari、Edge 都可以）打开。
2. 把 MP3 文件或整个文件夹拖进网页，子文件夹也会一起读取。
3. 检查预览表格。带橙色竖线的行建议看一眼，可以直接改字，或者点「对调」交换歌手和歌名。
4. 点「下载修复后的文件」，得到一个 zip。
5. 在 Apple Music 里先删掉旧的乱码歌曲，再导入解压后的新文件。

## 信息从哪里来

工具按下面的顺序找歌名和歌手：

1. APE 标签
2. ID3v2 标签
3. ID3v1 标签（按 GBK 重新解码）
4. 文件名（用内置的歌手名字库拆分，支持 `歌手 - 歌名`、`歌名-歌手`、`歌手歌名` 等写法）

## 说明

- 所有处理都在你的浏览器里完成，文件不会上传。
- 支持离线使用。
- 不会修改原文件，只生成新文件。
- 封面图片和其他标签信息会保留。
- 会自动跳过 Mac 生成的 `._` 隐藏文件。
